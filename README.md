# ClassicalQuiz

A classical music quiz that tests whether you actually know your Beethoven from your Brahms. Vanilla JavaScript, no framework overhead — just questions, audio clips, and the gentle humbling of realizing you can't tell Debussy from Ravel.

## Features

- **Audio-based questions** — listen to a clip, identify the composer/piece
- **Multiple quiz modes** — composer identification, era matching, instrument recognition
- **Progressive difficulty** — starts with the greatest hits, ends with deep cuts
- **Score tracking** with personal best records
- **Educational mode** — learn about each piece after answering

## Tech Stack

- Vanilla JavaScript
- HTML5 Audio API
- CSS3 animations
- Zero dependencies

## Getting Started

```bash
git clone https://github.com/sebastiandoyle/ClassicalQuiz.git
cd ClassicalQuiz
open index.html
```

No build step. Open the HTML file and start playing.
